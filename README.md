# PatchNotes

Registry of notes for [PatchEditor](https://github.com/Dustdustry/PatchEditor).

# Contribute Your Notes

This registry is welcome for your contribution.

To contribute your notes, just follow the steps as bellow:

1. Upload or modify the notes in the [contribution directory](./contributions).
2. Create a pull request.

Here's an example for contribution notes:

```json
{
    "name": "notes-example",
    "contributors": ["minRi2"]
    "notes": {
        "Block": {
            "consumes": "Describe the possible consumption of items, liquids, power and payloads."
        }
    }
}
```
